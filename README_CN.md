# 终端斗地主 (Ink + Node.js)

这是一个基于 Node.js 和 Ink 开发的终端版斗地主小游戏。支持局域网联机对战，并内置了 AI 角色，方便在人数不足时进行游戏。

## 功能特点

-   **终端 UI**: 使用 [Ink](https://github.com/vadimdemedes/ink) (基于 React 的命令行 UI 库) 构建，界面精美。
-   **局域网联机**: 基于 Socket.io 实现，支持同一局域网下的多玩家对战。
-   **AI 填充**: 当玩家人数不足 3 人时，可以自动填充 AI 玩家。
-   **完整逻辑**: 实现了洗牌、发牌、抢地主、出牌校验（单张、对子、三带一、顺子、连对、炸弹、王炸等）以及胜负判定。
-   **跨平台**: 支持 macOS、Linux 和 Windows (建议在支持 Unicode 字符的终端下运行)。

## 技术栈

-   **语言**: TypeScript
-   **UI 框架**: Ink (React)
-   **网络**: Socket.io & Socket.io-client
-   **工具**: meow (命令行参数解析), chalk (色彩渲染)

## 快速开始

### 1. 安装依赖

首先进入项目目录并安装必要的依赖包：

```bash
cd ink-doudizhu
npm install
```

### 2. 启动游戏

#### 作为房主启动 (Host)
房主模式会自动启动一个局域网服务器。默认会添加两个 AI 玩家以便快速开始。

```bash
npm run start -- --mode host --name 你的名字
```
*启动后，屏幕上会显示你的局域网 IP 地址（例如 `192.168.1.5:3000`），你可以分享给好友。*

#### 作为玩家加入 (Join)
如果你的好友已经开启了游戏，你可以通过他们的 IP 地址加入：

```bash
npm run start -- --mode join --host <房主IP> --name 你的名字
```

### 3. 操作指南

-   **左右方向键**: 在手牌中切换焦点。
-   **空格键**: 选中或取消选中当前焦点的牌。
-   **回车键 (Enter)**: 尝试打出选中的牌组。
-   **'P' 键**: 跳过当前回合（过牌）。
-   **Esc 键**: 退出游戏。

## 项目结构

-   `src/core`: 核心游戏逻辑，包括洗牌 (`deck.ts`)、规则校验 (`rules.ts`) 和 AI 算法 (`ai.ts`)。
-   `src/server`: 游戏服务端逻辑，管理房间状态和网络通信。
-   `src/client`: 客户端 UI 逻辑，使用 Ink 渲染游戏界面。
-   `src/types`: TypeScript 类型定义。
-   `src/index.tsx`: 程序入口，负责命令行参数解析和模式切换。
